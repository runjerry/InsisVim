# Personal Codex instructions

## Markdown math formatting

- When creating or editing Markdown, use `$...$` for inline mathematical notation and equations.
- Use `$$...$$` for display equations. Put each opening and closing `$$` on its own line, with a blank line before and after the entire math block.
- Do not use `\(...\)` or `\[...\]` as Markdown math delimiters.
- Use standard LaTeX syntax for mathematical symbols, Greek letters, subscripts, and superscripts. Do not format mathematical expressions as inline code.
- Keep function names, field names, configuration options, commands, and file paths in code formatting.
- Before finishing a Markdown edit, check that math delimiters are paired and mathematical notation follows these rules.
- These rules do not apply to literal examples inside code spans or fenced code blocks, or to `.tex` files.
